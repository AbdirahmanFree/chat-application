# Chat Application - Customer Policy
Vision: Browser-based communication through text, voice and video

- CP-01: Users can create an account.
- CP-02: Each Account should be associated with a unique email address.
- CP-03: Each account should have a unique username.
- CP-04: Users can sign in to their account.
- CP-05: Users can sign out of their account.
- CP-06: Users are assigned profile icons which default to their initals.
- CP-07: Users can click on their profile icons to view their profile page
- CP-08: Profile Pages always show date joined username and profile icon.
- CP-09: Users can sign out of their account from their own profile page.
- CP-10: When viewing another user's profile, users can select a chat icon to open a direct messaging interface. If a conversation already exists, its message history is displayed.
- CP-11: Users can search for other users in a search bar using their usernames.
- CP-12: Users can initiate direct conversations and exchange messages with other users.
- CP-13: Messages in the MVP are text only.
- CP-14: All existing conversations appear in the chat lists of their participants.
- CP-15: A conversation between two users is created when the first message is sent, provided a conversation between them does not already exist.
- CP-16: Two users may have only one shared one-to-one conversation.
- CP-17: Users in a chat can send text messsages to each other.
- CP-18: Users in a chat can view previously sent text messages.
- CP-19: Only Participants in a conversation may view its messages.

## Constraints 

- C-01: The application must be accessible through modern web browsers.
- C-02: The application must protect user account information and private conversations.
- C-03: The application must provide an accessible and mobile-friendly user interface.
